# 운동 루틴 기획 (초안)

운동 기록을 루틴으로 바꾸는 기획이다. 웨이트를 하는 사람은 매일 운동한 종목을 찾아 적는 게 가장 귀찮다. 루틴을 한 번만 만들면, 그다음부터는 오늘 할 날을 열고 세트마다 체크만 하게 한다.

아직 구현하지 않았다. 지금 앱의 운동 기록(종류와 시간 고르기)은 이 기획이 들어가면 바뀐다. 앱 전체 기준은 `docs/v1-app-plan.md`다.

## 1. 정한 것

| 항목 | 결정 |
| --- | --- |
| 루틴 방식 | 순환 분할. A → B → C → A … 순서로 돈다. 쉰 날이 있어도 순서는 밀리지 않는다 |
| 기록 단위 | 세트별 무게와 횟수. 지난번 값이 미리 채워진다 |
| 종목 목록 | 앱이 주는 기본 목록과 내가 추가하는 종목 |
| 웨이트가 아닌 운동 | 루틴에 함께 넣는다. 러닝 30분 같은 항목이 된다 |
| 루틴 만들기 | 템플릿을 고르고 고친다 |
| 기록 시점 | 헬스장에서 세트마다 체크한다. 쉬는 시간 타이머가 있다 |
| 그룹 공개 | 종목과 무게까지 보인다. 친구 루틴을 내 루틴으로 가져올 수 있다 |
| 점수와 O | 운동 완료를 누르면 O. 점수는 지금처럼 +20, 운동 시간 30분 이상이면 +5 |

## 2. 사용자 흐름

### 2.1 처음 한 번: 루틴 만들기

운동 기록 → 루틴 만들기 → 템플릿 고르기 → 날마다 종목, 세트, 횟수 고치기 → 저장.

- 템플릿은 무분할, 2분할, 3분할, 5분할이다. 구성은 4장에 있다
- 날 이름(A 밀기 …)과 순서를 바꿀 수 있다. 날을 더하거나 뺄 수 있다
- 종목은 기본 목록에서 고르거나 이름을 적어 추가한다
- 편집 화면의 종목 줄마다 kg 칸이 있어 시트를 열지 않고 무게를 적는다. 템플릿으로 막 만든 루틴은 무게를 넣으라는 안내가 뜨고 빈 kg 칸이 강조된다. 비워 두면 첫 운동에서 적은 무게를 다음부터 쓴다
- 다음 운동은 루틴 무게와 지난번 운동 무게 중 더 최근에 바뀐 쪽으로 채운다. 지난 운동 뒤에 루틴 무게를 고쳤으면 루틴 무게를 쓰고, 그 종목은 증량 제안을 하지 않는다. 템플릿이나 친구 루틴에서 복사한 직후에는 고친 시각이 없어 지난번 운동 무게가 앞선다

### 2.2 매일: 오늘 운동

운동 기록 화면은 위쪽 탭으로 [기록 | 루틴]을 나눈다.

- 기록 탭: 월·주·일 달력. 진행 중인 운동이 있으면 맨 위에 이어 하기가 나온다
- 루틴 탭: 사용 중인 루틴 카드(`오늘은 B 당기기 · 지난 운동 A 밀기`, 오늘 할 날의 종목, 순서대로 도는 날), 다른 루틴(사용하기), 새 루틴 만들기
- 오늘 할 날은 이 루틴으로 마지막에 한 날의 다음 날이다

두 탭 아래에 [운동 기록하기]가 있다. 누르면 시트가 열린다.

- 위에서 [어제 / 오늘]을 고른다. 오늘은 세트마다 체크하는 진행 화면, 어제는 같은 표를 타이머 없이 채운다
- **루틴으로 기록**: 오늘 추천 날로 시작한다. [다른 날]로 바꿀 수 있다
- **일회성 운동**: 루틴에 없는 운동을 한 날. 빈 운동에서 종목을 골라 기록한다. 루틴 순서에는 들어가지 않는다
- **오늘은 쉬어요**: 휴식 데이로 남긴다. 달력에는 휴로 보이고, 순서는 그대로다
- 진행 중인 운동이 있으면 버튼이 [진행 중인 운동 이어 하기]가 되고, 시트 없이 진행 화면을 연다

### 2.3 진행 화면

```
B 당기기 · 32:10 진행 중

랫풀다운                     지난번 45kg × 10
  ✓ 1  45kg × 10
  ✓ 2  45kg × 10
  □ 3  45kg × 10   ← 쉬는 중 1:12
  □ 4  45kg × 10
바벨 로우  0/4
페이스풀  0/3

[ + 종목 추가 ]        [ 운동 완료 ]
```

- 세트 줄에는 지난번 무게와 횟수가 미리 들어 있다. 같으면 체크만, 다르면 고치고 체크한다
- 체크하면 쉬는 시간 타이머가 돈다
- 세트 추가와 삭제, 종목 추가와 바꾸기, 순서 바꾸기를 할 수 있다
- 유산소 항목은 시간이나 거리를 적고 체크한다
- 위에는 경과 시간이 보인다

### 2.4 완료

운동 완료를 누르면 요약이 나온다. 총 시간, 완료한 세트 수, 볼륨(kg × 회 합), 개인 최고 기록을 보여 준다.

저장하면 그 날 운동에 O가 붙고 점수가 오른다. 다음 추천 날로 넘어간다. 세트를 하나도 체크하지 않았으면 완료할 수 없다.

### 2.5 보기

- 운동 기록의 월과 주 보기는 지금처럼 O / X / 휴다. 주 카드 설명에 `B 당기기 · 5종목 · 52분`이 들어간다
- 일 보기는 종목별 세트 표다
- 멤버 방에서 친구의 세션을 종목과 무게까지 본다. 친구 루틴은 [이 루틴 가져가기]로 내 루틴에 복사한다

## 3. 데이터 방향

| 테이블 | 내용 |
| --- | --- |
| `exercises` | 기본 종목과 내가 추가한 종목. 이름, 부위, 장비, 기록 방식 |
| `routines` | 내 루틴. 이름, 사용 중 여부 |
| `routine_days` | 루틴의 날. 순서, 이름(A 밀기 …) |
| `routine_items` | 날의 종목. 순서, 목표 세트 수, 목표 횟수, 목표 무게 또는 시간·거리 |
| `workout_sessions` | 한 번의 운동. 날짜, 루틴 날, 시작과 끝 시각, 완료 여부 |
| `session_sets` | 세트. 종목, 세트 번호, kg와 횟수 또는 분과 km, 체크 여부 |

- 기록 방식은 네 가지다. kg × 회, 회(맨몸), 시간, 시간 + 거리
- 세션을 완료하면 서버 트리거가 그 날 하루 기록에 운동 표시와 운동 시간을 넣는다. 식단의 `has_meal`과 같은 방식이라 출석, 점수, 스트릭이 그대로 돈다
- 지금의 `workout_kinds`와 `workout_minutes`는 예전 기록을 보여 주는 데만 남긴다
- 친구에게 보이는 범위는 하루 기록과 같다. 같은 그룹에 있으면 세션과 세트를 본다

## 5. 세부 규칙

- **어제 운동**: 어제 날짜로는 타이머 없이 표로 한꺼번에 채운다. 진행 화면과 같은 표를 쓰고, 시작과 끝 시각 대신 운동 시간을 적는다
- **이어 하기**: 진행 중인 운동은 세트를 체크할 때마다 휴대폰에 저장한다. 앱이 꺼졌다 다시 열리면 "진행 중인 운동이 있어요"로 이어 한다. 날짜가 바뀐 뒤에도 끝내지 않았으면, 시작한 날 기록으로 완료하거나 버린다
- **쉬는 시간 타이머**: 종목마다 정한다. 기본값은 장비와 종류로 정한다 (6장)

## 6. 증량 제안

종목마다 증량 방식을 정한다. 운동을 시작하면 조건을 채운 종목이 한 화면에 모여 나온다. 종목마다 받기나 넘기기를 고르고, [모두 받고 시작]으로 한 번에 받을 수도 있다. 받은 종목은 세트 줄의 무게나 횟수가 바뀌고, 넘긴 종목은 지난번 값 그대로다. 올려 볼 종목이 없으면 이 화면은 건너뛴다.

```
오늘 올려 볼 종목

벤치프레스   60 → 62.5kg     [받기] [넘기기]
랫풀다운     12회 → 45kg×8   [받기] [넘기기]
풀업         8 → 9회         [받기] [넘기기]

[ 모두 받고 시작 ]
```

| 방식 | 조건 | 다음 제안 |
| --- | --- | --- |
| 무게 올리기 | 지난번 모든 세트에서 목표 횟수를 채움 | 무게 + 증량 단위 |
| 횟수 먼저, 다음 무게 (더블 프로그레션) | 목표 범위(예: 8–12회)의 위끝을 모든 세트에서 채움 | 무게 + 증량 단위, 횟수는 범위 아래끝으로 |
| 횟수 올리기 | 모든 세트에서 목표 횟수를 채움 | 횟수 + 1 (맨몸 종목) |
| 시간 올리기 | 목표 시간을 채움 | 시간 + 증량 단위 (플랭크, 유산소) |
| 제안 안 함 | | |

종목 장비에 따른 기본값:

| 장비·종류 | 증량 방식 | 증량 단위 | 쉬는 시간 |
| --- | --- | --- | --- |
| 바벨 하체 (스쿼트, 데드리프트 …) | 무게 올리기 | 5kg | 180초 |
| 바벨 상체 (벤치, 오버헤드 프레스 …) | 무게 올리기 | 2.5kg | 150초 |
| 덤벨 | 더블 프로그레션 | 2kg | 90초 |
| 머신·케이블 | 더블 프로그레션 | 2.5kg | 90초 |
| 맨몸 | 횟수 올리기 | 1회 | 90초 |
| 코어 (시간) | 시간 올리기 | 10초 | 60초 |
| 유산소 | 제안 안 함 | | 없음 |

- 루틴 편집에서 종목마다 방식, 단위, 쉬는 시간을 바꿀 수 있다
- 세트를 하나라도 못 채웠으면 제안하지 않고 같은 무게를 둔다. 여러 번 연속으로 못 채워도 앱이 무게를 내리자고 하지 않는다. 내리는 건 사용자가 직접 한다
